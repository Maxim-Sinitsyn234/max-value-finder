# Поиск максимального значения в большом массиве

Программа генерирует большой слайс случайных положительных чисел и ищет в нём максимум двумя способами:

- в одном потоке;
- в восьми горутинах, каждая из которых обрабатывает свою часть слайса.

Результат и время поиска выводятся в микросекундах.

## Структура

```
main.go      — генерация данных, поиск максимума, запуск горутин
main_test.go — unit-тесты
```

## Запуск

```bash
go run .
```

По умолчанию `SIZE = 100_000_000`. Для быстрой проверки можно уменьшить константу `SIZE` в `main.go`, например до `10_000_000`.

## Тесты

```bash
go test ./...
```

Подробный вывод:

```bash
go test -v ./...
```

## Как работает

`generateRandomElements` создаёт слайс заданного размера и заполняет его случайными числами от 1 до 1000. Для нулевого или отрицательного размера возвращается пустой результат.

`maximum` последовательно перебирает элементы и хранит наибольшее значение. Для пустого слайса возвращается 0.

`maxChunks` делит слайс на `CHUNKS` частей, запускает для каждой отдельную горутину, собирает восемь локальных максимумов и выбирает из них общий максимум. Последняя часть забирает остаток элементов, если длина слайса не делится на 8.
